# KinoPub 1.0.73-mx.22 для Lampa MX

Подготовленная ветка `fix/infuse-device-native-audio-mx22`: проверка отдельного устройства Infuse, защита от поздних ответов и полный HLS4-источник для трёх нативных tvOS-режимов. Причина остановок Infuse и реальное переключение аудио на Apple TV пока не подтверждены. Прямой файл максимального качества для Infuse сохранён.

До публикации для проверки кода mx.22 доступен адрес:

```text
https://cdn.jsdelivr.net/gh/aomikh/lampa_kinopub@498d58bdd9b6eb353c1910e4d4c3b6402f5f3c1b/docs/kp.js
```

У этого адреса проверены HTTP 200, тип application/javascript и точное совпадение байтов проверенного kp.js. GitHub Raw отдаёт text/plain с nosniff; загрузчик Lampa использует script src, поэтому Raw не рекомендуется как адрес расширения. CDN используется только для доставки тестового скрипта; существующая передача видео сохраняется. После подтверждения публикации используй обычный Pages-адрес ниже. На самом Apple TV установка ещё не проверена.

В main/Pages пока остаётся mx.21. Подробные сценарии: [проверка Apple TV](audit/apple-tv-verification-mx22.md).

## Установка после публикации

1. После подтверждения коммита и завершения Pages замени адрес существующего расширения на `https://aomikh.github.io/lampa_kinopub/kp.js?v=1.0.73-mx.22`. Оставь одну активную копию KinoPub, полностью закрой и заново открой Lampa MX.
2. Открой Настройки → KinoPub → «Infuse: подключить отдельное устройство».
3. Если отдельный вход уже сохранён в mx.21, новый код не нужен. При первой привязке введи код на https://kino.pub/device и дождись подтверждения. Вход каталога сохраняется отдельно.
4. Выбери Infuse как внешний плеер и используй обычный запуск фильма или серии. Если отдельное устройство ещё не подключено, первая попытка воспроизведения предложит код и продолжится после подтверждения.
5. Формат и качество для Infuse выбирать не нужно. При наличии файлов разного разрешения выбирается наибольшее. Недоступный или неоднозначный файл не заменяется менее качественным.

Адрес с `?v=...` меняет ключ кэша, но не подтверждает публикацию или установку версии. До отправки в main и завершения GitHub Pages по публичному адресу остаётся прежний код. Публикация фиксируется отдельно.

## Как устроен отдельный вход Infuse

Интеграция Lampa с Infuse создаёт собственную привязку в KinoPub: отдельный код, токены и id, название «Lampa MX / Infuse / Apple TV» или соответствующее устройство Apple. Описание проверяется чтением `/device/info` после `/device/notify`. Включаются документированные возможности устройства для 4K и расширенных видеоформатов. Каталог и другие плееры продолжают пользоваться прежним входом. Название не доказывает изменение серверного типа клиента: существующий client_id остаётся xbmc.

Код плагина хранит и обновляет токены этого отдельного устройства. Перед запуском он получает карточку и прямую ссылку через отдельный вход, передаёт Infuse подписанный адрес без токенов. Это привязка для запуска внешнего плеера; самого интерфейса входа KinoPub внутри приложения Infuse команда запуска не добавляет.

Повторный код при каждом запуске не нужен. Временный сетевой сбой не удаляет вход. Если KinoPub отозвал токены, потребуется повторное подтверждение. «Infuse: отключить устройство» удаляет только локальный вход Infuse; запись устройства можно удалить в аккаунте KinoPub.

## Safari, iPhone и iPad

Отдельный Safari-скрипт ниже относится к прежней поставке; в этой ветке он не менялся и заново не проверялся.

Обновлённый текстовый скрипт StopTheMadness Pro 0.3.0 передаётся отдельно. Замени старый код целиком в Custom JavaScript (пользовательский JavaScript) для `kino.watch`, отключи прежние правила URL Redirects (перенаправления адресов) для KinoPub и перезагрузи страницу.

Один раз подтверди устройство «Infuse (Safari)». Уже сохранённый вход версии 0.2.1 используется повторно. При открытии фильма или серии скрипт заранее получает прямую ссылку максимального качества. Обычная кнопка ▶ на видео запускает Infuse. Дополнительной панели «Открыть в Infuse» и меню формата нет. Настройки подключения и диагностика свёрнуты под видео.

Если нажать ▶ до завершения подготовки, дождись её и нажми ▶ повторно. Переход в приложение выполняется синхронно из нажатия пользователя. Автоматического открытия приложения из фонового запроса или при загрузке страницы нет.

Системное окно iOS «Открыть в приложении Infuse?» остаётся под управлением системы. Скрипт не может отключить его. Документированный интерфейс Firecore использует `infuse://`; универсальный адрес для передачи произвольного видео без подтверждения в нём не указан.

## Проверка на устройстве

Проверь наличие нового пункта входа, затем запуск, перемотку, дорожки, субтитры и продолжение просмотра. «Infuse: последняя передача» показывает версию, прямой формат, качество и этап без секретных адресов. Передача ссылки не подтверждает воспроизведение.

Для Online, Universal и Pro выбери существующий формат «Авто»: будет передан полный серверный HLS4-источник. Явная настройка HLS2/другого формата не сбрасывается. Выбор аудио выполняется в собственном меню плеера, если оболочка поддерживает дорожки этого источника. Плагин не выдаёт сохранённую JS-озвучку за реально выбранный нативный звук. Наличие переключения, сохранение качества/позиции/субтитров и следующая серия требуют проверки каждого режима на устройстве. Подтверждённого интерфейса принудительного выбора до запуска сейчас нет.

Прошли 130 проверок JavaScript (8 настоящих адаптеров ядра), 22 локальные проверки HTTP/HLS и 20 проверок загрузки. Новую редакцию на физическом устройстве не запускали. Для Infuse требуется просмотр минимум 30 минут и дольше прежнего интервала до остановки. [Точный сценарий и журналы](audit/apple-tv-verification-mx22.md).

Откат тестовой установки: верни опубликованный URL mx.21 и полностью перезапусти Lampa. Ветка содержит исправление кода и последующий коммит инструкции. После публикации откат выполняется git revert обоих коммитов mx.22 в обратном порядке и обычным Pages deploy, без переписывания истории. Токены mx.21 сохраняют совместимость.
