# Установка единственной актуальной копии KinoPub

Репозиторий: https://github.com/aomikh/lampa_kinopub, единственная ветка `main`. Публикуется `docs/kp.js`. Текущая редакция: **1.0.73-mx.5**. Отдельные старые копии плагина удалены из публикации. История Git и исторические протоколы проверок сохранены.

Постоянный адрес: https://aomikh.github.io/lampa_kinopub/kp.js

Для обхода кэша при этом обновлении используй https://aomikh.github.io/lampa_kinopub/kp.js?v=1.0.73-mx.5. Это тот же единственный файл; параметр `v` не создаёт отдельную копию и не закрепляет версию.

## На Apple TV

1. Lampa MX → Настройки → Расширения. Замени прежний адрес KinoPub на адрес с `?v=1.0.73-mx.5`. Отключи дубликаты; оставь один KinoPub.
2. Полностью закрой Lampa MX и Infuse через переключатель приложений Apple TV. Запусти Lampa MX вновь. Авторизация и Shadowrocket сохраняются.
3. В списке KinoPub удерживай кнопку подтверждения на фильме → **Infuse: выбрать качество → 720p**, если этот вариант доступен. Сравни время начала и место прежнего обрыва на том же фильме; затем повтори 1080p. Качество выбирается только на этот запуск, обычное нажатие сохраняет прежнее поведение. Проверяй звук, перемотку и возврат. Название редакции можно увидеть в «Настройки → KinoPub → Диагностика Infuse» после попытки запуска.
4. Если вновь произошла остановка, вернись в **работающую сессию Lampa MX**, не закрывая её принудительно. Открой **Настройки → KinoPub → Диагностика Infuse**, дождись отчёта (до 12 секунд) и пришли снимок. Укажи название/год фильма, версию Infuse и минуту остановки. Полная ссылка и токены не нужны.

Диагностика показывает только безопасные сведения: редакцию плагина, версию ядра Lampa, сервер без пути, качество, время подготовки ссылки, время после передачи, статус HEAD и GET с диапазоном 0–1023, доступные заголовки и конечный сервер перенаправления. Тела ответов не читаются; запросы прерываются после заголовков, даже если сервер игнорирует Range. Проводится только по нажатию кнопки и не замедляет обычный запуск.

Проверка выполняется из Lampa, а не из Infuse. `?` означает отсутствующий или скрытый политикой CORS заголовок. Ошибка «сеть или CORS» не доказывает недоступность сервера для Infuse. Проверка заголовков не измеряет скорость и не подтверждает загрузку всего фильма. Если оболочка не поддерживает проверку, это будет указано явно.

## Что исправлено и что пока неизвестно

В mx.5 добавлен явный выбор качества для Infuse без изменения глобальных настроек. Предлагаются только доступные файловые варианты, не выше установленного максимума качества. Если нужного качества нет, оно не выдумывается и не заменяется другим. Более низкое разрешение может уменьшить требования к каналу, но скорость конкретного файла ещё не измерена. Субтитры и дорожки сохранены. Автоматическое ускорение 1080p и устранение обрывов не заявляются.

Для фильма с известным `files[].file` убран повторный запрос карточки. Перед передачей остаётся один запрос свежей ссылки на точный файл с сохранением качества. Это сокращает подготовку **в Lampa**; скорость дальнейшей загрузки **в Infuse** определяется его соединением с видеосервером. Для эпизодов сохранено обновление карточки перед формированием списка; для старых ответов без `file` сохранено получение свежего `urls.http`.

Скриншот «Server is not responding» после начала видео не устанавливает причину: возможны недоступность видеосервера, прерывание соединения, истечение ссылки или особенности клиента. Изменение региона без замера, замена подписанного адреса и автоматическое снижение качества не применялись. Исправление обрыва на устройстве **не подтверждено**.

Дополнительный контролируемый опыт, если в Infuse выбран Auto: Настройки → Воспроизведение → Streaming Cache (кэш потокового воспроизведения) → Limited (ограниченный). Firecore описывает этот режим как вариант с меньшей начальной нагрузкой на канал: https://support.firecore.com/hc/en-us/articles/360015608854-Settings-Overview. Это отдельный диагностический опыт, не доказанный способ устранить текущую ошибку. Запомни прежнее значение и верни его, если эффекта нет. Код Lampa не управляет этим параметром Infuse.

## Возврат изменений

По просьбе пользователя старые файлы больше не публикуются. Для отката кода используется отменяющий коммит в `main`; история сохранена. Параметр `?v=1.0.73-mx.3` старый код не возвращает. Не удаляй данные приложений, авторизацию или настройки Shadowrocket.
