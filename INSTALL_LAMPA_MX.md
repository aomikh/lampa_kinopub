# KinoPub для Lampa MX

Постоянный адрес расширения:

```text
https://aomikh.github.io/lampa_kinopub/kp.js
```

Внутренняя версия текущей редакции: `1.0.73-mx.23`. Параметр версии в адресе не требуется. Рабочая ветка репозитория: `main`; GitHub Pages публикует папку `docs`.

## Обновление

1. В Lampa MX открой Настройки → Расширения и замени адрес существующего KinoPub на постоянный адрес выше. Оставь одну активную копию.
2. Сохрани адрес, полностью закрой Lampa MX и открой снова. При сохранении старой копии очисти кэш расширений средствами Lampa.
3. Существующий вход KinoPub сохраняется. Новый код требуется только для первого входа или после отзыва регистрации сервисом.
4. На Apple TV обычная кнопка «Смотреть» открывает KinoPub. Запускай фильм или серию через выбранный в Lampa плеер.

## Изменения mx.23

Удалены специальные настройки Infuse, отдельная авторизация, подготовка прямого файла, принудительный выбор максимального качества, дополнительное получение ссылок и собственная команда запуска Infuse. Если Infuse выбран в Lampa, запуском управляет встроенный адаптер самой Lampa. Формат и ограничение качества теперь общие. Плагин не читает и не обновляет старые отдельные токены Infuse; ранее созданная запись устройства в аккаунте KinoPub автоматически не удаляется.

Сохранены вход каталога KinoPub и его обновление токенов, изображения серий, озвучки, субтитры, позиция, обычный запуск из карточки, браузерный путь, VLC и Samsung Tizen. Для Online, Universal и Pro «Авто» по-прежнему передаёт полный HLS4-источник. HLS (HTTP Live Streaming, сегментная потоковая передача) содержит отдельные фрагменты видео; меню дорожек нативного плеера зависит от оболочки и состава источника. Явная настройка другого формата сохраняется. Реальное переключение аудио в этих оболочках по-прежнему требует проверки на Apple TV.

## Проверка

Подробные результаты: [изменения mx.23](audit/remove-infuse-mx23.md). Проверены код и реальные JavaScript-адаптеры Lampa, физические устройства недоступны.

## Откат

Версию файла определяет содержимое опубликованного `main`, а не параметр адреса. Для отката нужно отменить коммит mx.23 через `git revert` и дождаться обычной публикации GitHub Pages. Адрес расширения сохраняется. История предыдущих версий остаётся в `main`.
