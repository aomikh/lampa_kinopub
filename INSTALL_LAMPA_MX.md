# Установка опубликованной версии 1.0.73-mx.3

Исправленная копия размещена в репозитории https://github.com/aomikh/lampa_kinopub. GitHub Pages публикует папку `/docs` ветки `main`.

Проверенная ссылка для расширения Lampa MX:

https://aomikh.github.io/lampa_kinopub/kp.js?v=1.0.73-mx.3

Редакция mx.3 получает ссылку на выбранный файл отдельным методом KinoPub непосредственно перед запуском Infuse. Добавлены проверки ошибки и отмены запроса. Воспроизведение mx.3 на Apple TV ещё не подтверждено. Ранее пользователь сообщил о повторной ошибке фильмов в mx.2: `com.firecore.media.player, ошибка 1`.

SHA-256 mx.3: `18aef29d27c3780f9705ff5d42a8a5b6626298593ab8805c0c93ce0ee4bb7385`. Результат проверки опубликованного файла хранится в `audit/publication-mx3.json`.

Файлы на GitHub уже загружены, настройка Pages выполнена. Следующие действия требуются только на Apple TV.

## Подключение на Apple TV

1. В Lampa MX открой Настройки → Расширения. Отключи старую копию именно этого плагина KinoPub и его дубликаты. Сохрани старый адрес для отката. Не удаляй приложение и данные аккаунта.
2. Добавь `https://aomikh.github.io/lampa_kinopub/kp.js?v=1.0.73-mx.3`. Сохрани.
3. Полностью закрой Lampa MX через переключатель приложений Apple TV. Так же закрой Infuse, затем запусти Lampa MX снова. Простого перехода на домашний экран может быть недостаточно для очистки JavaScript-контекста. Старый флаг `online_kp_plugin` иначе может препятствовать загрузке новой копии.
4. Проверь версию 1.0.73-mx.3 в сведениях о плагине или в диагностической строке `[KP:boot] kp.js v1.0.73-mx.3 starting`. Предупреждение о другой активной копии означает, что нужно проверить список расширений и перезапуск.
5. Для проверенного пользователем Infuse 8.4.7 или новее выбери Infuse в настройках плеера Lampa либо в контекстном меню фильма/серии: «Запустить плеер - Infuse». Разовый выбор не меняет сохранённую настройку плеера. Выбор Infuse внутри неизвестного нативного меню `tvosSelect` не позволяет плагину заранее определить плеер; используй явный пункт Infuse.
6. Оставь действующие настройки авторизации, прокси API и Shadowrocket. Прямой файл выбирается именно для Infuse. Максимальное качество учитывается; при отсутствии файловой ссылки в этом качестве появится сообщение, а не случайная замена потоком HLS.

## Проверка на устройстве

1. Тот же фильм, на котором возникала ошибка: дождись начала видео в Infuse, проверь звук, затем перемотку на несколько минут. Открытие приложения само по себе не означает успех.
2. «Восьмидесятые», сезон 1, серия 1: проверь кадр и запуск. В полученном ответе TMDB кадра нет; результат зависит от изображения именно этой серии в KinoPub. Если оба источника недоступны, номер серии является ожидаемой заглушкой.
3. Материал с несколькими дорожками: выбери другую дорожку в Infuse и проверь звук. Доступность дорожек определяется фактическим файлом; параметр выбора дорожки интерфейс передачи Infuse не предоставляет.
4. Закрой воспроизведение и вручную вернись в Lampa MX. Автоматический возврат и синхронизация позиции не обещаются: зарегистрированная схема возврата этой оболочки не доступна для проверки. Убедись, что серия не получила отметку «просмотрено» только из-за передачи ссылки. Передача ранее сохранённой начальной позиции поддерживается; новая позиция из Infuse в Lampa не записывается.
5. Быстро переключи сезоны и закрой карточку во время загрузки кадров: изображение предыдущего сезона не должно появиться в новом списке.

## Откат

Отключи mx.3, добавь сохранённую mx.2: `https://aomikh.github.io/lampa_kinopub/releases/kp-1.0.73-mx.2.js`, полностью закрой и вновь открой Lampa MX. Оставь только одну активную копию. Старый параметр `?v=1.0.73-mx.2` у основного `kp.js` не является откатом: этот файл обновляется. Настройки и ключи авторизации сохраняются. Проблема фильмов в mx.2 может вернуться.

Если mx.3 не помогла, сообщи название и год фильма, качество, точную версию Infuse и момент ошибки (сразу/во время просмотра). Если сообщение появилось ещё в Lampa, нужен код `KP-I1`/`KP-I2` и HTTP-статус. Не присылай токены и подписанные ссылки.

Для рабочего Git-ответвления можно вернуть плагин отдельным отменяющим коммитом. Сначала проверь отсутствие собственных незакоммиченных изменений; не заменяй ими чужую работу. Исходная ревизия и самостоятельные коммиты исправлений перечислены в файле передачи задачи.
