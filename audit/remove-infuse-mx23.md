# Удаление специальных изменений Infuse

10.10.2026. Основание: прямой запрос пользователя убрать изменения Infuse, сохранить остальные функции, оставить только main и использовать постоянный адрес https://aomikh.github.io/lampa_kinopub/kp.js. База: 19bcebf8aeb5b0c62d8551284ae91055e7a41453, опубликованная mx.22. В начале рабочая копия чистая. Внутренняя версия новой редакции: 1.0.73-mx.23.

## Состав изменений

Из docs/kp.js удалены отдельный профиль и токены Infuse, проверка и настройка отдельного устройства, специальное получение item/media-video-link, собственный выбор максимального прямого файла, построение infuse://, подготовка списка серий, таймеры подготовки, запись этапов передачи, три настройки Infuse, дополнительный пункт запуска из контекстного меню и их переводы. Обычное скрытие подписанных адресов в журналах сохранено.

Infuse остаётся доступным как плеер самого ядра Lampa. Плагин передаёт воспроизводимый элемент обычному Lampa.Player.play: используется общая авторизация KinoPub, общий формат и общий предел качества. В «Авто» это HLS2, как для прочих внешних приложений. Код ядра управляет адресом запуска и системным переходом. Особого входа, обязательного максимума, перезапроса карточки или фоновых запросов Infuse больше нет. Старые отдельные токены не читаются и не обновляются, удаление записи устройства на сервере не выполняется.

Остальная функциональность сохранена: каталог, вход по коду, объединённое обновление токенов, отмена запросов, защита от поздних ответов, карточка «Смотреть», изображения серий, выбор общего качества/формата, озвучки, субтитры, позиция, плейлист, VLC, браузер и Samsung Tizen. Для Online/Universal/Pro сохранён полный HLS4 в «Авто», точный выбор файла и передача позиции/субтитров в плейлисте.

18 общих функций и 12 функций авторизации сравнены с mx.22: их код совпадает байт в байт. Перечень: [mx23-preserved-functions.json](mx23-preserved-functions.json). Обработка описания устройства упрощена до единственного прежнего профиля каталога, с сохранением пользовательского названия и прежней терпимости к временным ошибкам notify.

Обновлены текущие инструкции и постоянный адрес. Исторические журналы прежних версий сохранены. Старые тесты специального входа и запуска Infuse заменены проверками удаления механизма; общие проверки из смешанных файлов сохранены.

## Публикация и ветки

Запрос пользователя разрешает публикацию сразу. GitHub Pages публикует папку docs ветки main. Публичный файл проверяется по байтам и контрольной сумме из release.json. Параметр версии в адресе не используется.

В начале на GitHub были main, fix/infuse-device-native-audio-mx22 и codex/infuse-direct-device-20261008. Обе дополнительные ветки указывали на коммиты, уже включённые в main. После публикации их можно удалить без потери истории. Инструкции прошлых редакций о промежуточных ветках являются архивными.

Откат: git revert коммита удаления и обычная публикация Pages. История не переписывается; внешний адрес и общая регистрация KinoPub сохраняются.
