# Lampa kinopub plugin

Плагин-источник видео [kinopub](https://kino.pub) для медиацентра [Lampa](https://github.com/yumata/lampa). Ориентирован на Samsung Tizen (Tizen TV), работает также на webOS, Android и в браузере.

## Установка

Прямая ссылка плагина:

```
https://aomikh.github.io/lampa_kinopub/kp.js
```

В Lampa: Настройки → Расширения → Добавить плагин → вставить URL → Сохранить.

## Авторизация

При первом запуске плагин показывает Device Flow код kinopub — открыть [kino.pub/device](https://kino.pub/device) на телефоне или ПК, ввести код, и плагин автоматически продолжит работу.

## Настройки

`Настройки → KinoPub`:

| Поле                | Назначение |
|---------------------|------------|
| URL лог-сервера     | Адрес [log-server](./log-server/) для удалённых логов с ТВ |
| Макс. качество      | Верхняя граница потока |
| Формат потока       | http / hls / hls2 / hls4 / авто |
| CORS-прокси         | Опционально, на Tizen не нужен |
| Авторизоваться      | Открыть окно с кодом для kino.pub/device |
| Выйти из аккаунта   | Удалить токены |

## Лог-сервер

`log-server/` — мини Node.js сервер для приёма JSON-логов от плагина. См. [log-server/README.md](./log-server/README.md).

## Структура

```
.
├─ docs/        # содержимое GitHub Pages (kp.js, index.html)
│  └─ kp.js       # сам плагин
├─ log-server/    # мини HTTP сервер для удалённого логирования
└─ filmix.js      # рабочий пример другого источника (для сверки API Lampa)
```

## Лицензия

MIT (плагин). Плагин не аффилирован с kinopub. Используется публичный xbmc-клиент Device Flow OAuth, известный сообществу неофициальных клиентов.

## Текущая редакция 1.0.73-mx.13

В списке KinoPub удержать строку видео и выбрать **Infuse: источник как у VLC**. Новый разовый режим передаёт один готовый адрес без обновления, позиции, названия и внешних субтитров. Не меняет сохранённые настройки и обычный запуск Infuse. Это сравнение источников, не подтверждённое исправление скорости. [Подробности](https://github.com/aomikh/lampa_kinopub/blob/main/audit/infuse-vlc-source-mx13.md).

Добавлена отключаемая запись этапов запуска на Apple TV. Включение в «Настройки → KinoPub → Запись этапов запуска», просмотр в «Отчёт последних запусков». По умолчанию выключена. Только 8 попыток в памяти, безопасные метки файлов и адресов, без новых запросов к видео. Это диагностическая редакция, не подтверждённое ускорение Infuse.

Изменения предыдущей mx.11 сохранены:

Обновляйте существующее расширение, оставляя одну копию: https://aomikh.github.io/lampa_kinopub/kp.js?v=1.0.73-mx.13.

Исправлены повторная привязка «Смотреть», замена элемента кнопки, повторные/устаревшие действия и выбор неподтверждённого материала. Открывается список KinoPub текущего фильма или сериала; автоматического запуска первой серии нет. Дублирующая кнопка не создаётся.

Для Infuse фиксируются выбранные файл и разрешение серии; смена плеера/материала отменяет ожидающий запуск. На Apple TV убран лишний отладочный запрос видео во внутреннем веб-плеере; делегированные плееры соблюдают явный выбор и предел качества. Настройки, Tizen, изображения эпизодов, реклама и сеть не менялись.

**Причина медленного запуска и остановок Infuse ещё не установлена.** Кодовые проверки не подтверждают устранение ошибки на Apple TV. Последняя подтверждённая пользователем версия на устройстве: mx.12, подготовка обычного Infuse 414 мс, до вызова передачи ещё 1 мс. Прежний HLS2-тест mx.10 завершился ошибкой «Сервер не сообщил размер файла»; новый режим не использует тот же механизм получения ссылки. Обычный Infuse сохраняет прямую файловую доставку.
